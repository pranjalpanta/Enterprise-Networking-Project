#Enterprise Network Design and Configuration 

## 📌 Project Overview

This project presents the design and implementation of a multi-zone enterprise network using Cisco Packet Tracer.

The network is divided into three major zones:

- Access Zone
- Distribution Zone
- Core Operations Zone

The project demonstrates enterprise networking concepts including routing, DHCP, NAT, ACL, VPN, and network segmentation.

## 🏢 Network Architecture

### Access Zone

The Access Zone contains:

- HR Department
- IT Department
- Training Department
- Development Department

### Distribution Zone

The Distribution Zone contains:

- Logistics and Supply Chain Department
- Remote Office Operations
- Sales and Marketing Department

### Core Operations Zone

The Core Operations Zone contains:

- Data Center Operations
- Finance and Accounting Department
- Research and Development Department

## 🔧 Technologies and Protocols

- Cisco Packet Tracer
- RIP Routing
- OSPF Routing
- EIGRP Routing
- DHCP
- NAT
- ACL
- VPN
- Cisco Routers
- Cisco Switches
- Network Servers
- End Devices

## 🌐 Network Features

### Routing

Different routing protocols are implemented across different network sections:

- RIP
- OSPF
- EIGRP

### DHCP

DHCP servers are configured to automatically assign IP addresses to network devices.

### NAT

Network Address Translation is implemented to provide appropriate network address translation between network segments.

### ACL

Access Control Lists are used to control and restrict network traffic.

### VPN

VPN connectivity is included to provide secure communication between network locations.
